# Tamil Nadu Assembly Election 2026 Analysis

## Overview

This project was completed as part of the Codebasics Resume Project Challenge.

The objective was to analyze the Tamil Nadu Assembly Election 2026 results using publicly available Election Commission of India (ECI) data and identify key election stories through data analysis and storytelling.

## Research Questions Selected

1. Geographic Story – Regional seat distribution changes between 2021 and 2026.
2. Flip Story – Constituencies where the winning party changed.
3. Margin of Victory Story – Changes in electoral competitiveness.

## Key Findings

* 163 of 234 constituencies changed winning parties.
* South Tamil Nadu recorded the highest number of seat flips.
* Average victory margin decreased from 22,871 votes in 2021 to 16,784 votes in 2026.
* Multiple constituencies were decided by extremely narrow margins.

## Tools Used

* Python
* Pandas
* Jupyter Notebook
* Power BI

## Data Sources

* Election Commission of India (ECI)
* Codebasics Challenge Dataset

## Reproduction Steps

1. Load all CSV files.
2. Identify winning candidates for 2021 and 2026.
3. Compare winning parties by constituency.
4. Calculate seat flips and regional changes.
5. Calculate margins of victory.
6. Build dashboard and presentation.

## Disclaimer

This analysis is strictly descriptive and non-partisan. No attempt has been made to explain why parties won or lost, nor to predict future outcomes.
